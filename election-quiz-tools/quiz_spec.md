# 政見配對資料檔規格（所有選區共用）

選舉：2026-11-28（民國115年）直轄市長、直轄市議員選舉。今天：2026-11-21。
**參考範本（必讀）**：`/home/user/usagi-game/election-quiz/data/ntpc-c04.js`（議員）與 `data/ntpc-mayor.js`（市長）。新檔格式、語氣、深度都要與範本一致。

## 檔案格式
一個檔案 = 一個選區，路徑 `/home/user/usagi-game/election-quiz/data/<id>.js`，內容只有：
```
REGISTER({ ...JSON... });
```
JSON 欄位：
- `id`（如 "tpe-c03"）、`kind`："mayor" 或 "council"、`city`："臺北市"/"新北市"
- `title`：如 "臺北市議員第3選舉區"；`areas`：行政區陣列（原住民選區為 []）；`seats`、`women`（應選名額、婦女保障名額，依中選會公告）
- `bulletin`：官方公報 PDF 網址（必須是 bulletin.cec.gov.tw 或 eebulletin.cec.gov.tw 實際可下載的連結）
- `asof`："2026-11-21"；`verified`：留空字串 ""（驗證者填日期）
- `integrityTargets`：本人目前「遭起訴尚未判決」或「有罪判決」的候選人 id 陣列（只看正式司法程序，不看指控、家屬、不起訴、無罪）
- `candidates`：陣列，**公報上所有候選人都要列**，id 依號次：議員 "c1","c2"...，市長 "m1","m2"...（同一檔案內唯一即可）
- `questions`：陣列（議員 12–16 題，市長 10–13 題）

### candidate 物件
```
{ id, no, name, party, gender, born:"民國XX年・出生地", inc:true/false（是否現任本職，市長檔可省略）,
  edu:[公報學歷], exp:[公報經歷，最多5項],
  slogan:"（市長檔可加）",
  platform:[公報政見摘要，4–10條，保留具體數字與地名],
  check:[{s:"ok"|"warn"|"na", t:"查核說明", u:"來源"}],     // 學經歷與主要政見查核，ok=已證實 warn=有爭議 na=未證實
  pos:[{t, u}],                                             // 正面紀錄（問政成果、評鑑、獲獎），至少1筆；查無就寫一筆「查無…（公開資料有限）」u:""
  rec:[{k, t, u}],                                          // 爭議與司法紀錄
  promise: null | {na:"說明"} | {rate, basis, done, partial, no, unk, note, items:[{s,t,u}]}
}
```
- `rec.k` 只能用：accuse 指控／indict 起訴中／ruling 判決（寫明審級、是否確定、是否本人）／agency 機關認定／critique 政治批評／victim 被害方／party 黨紀／none 查無（t 寫「查無負面報導（公開資料有限）」）
- 每筆 t 都要客觀、具體、有日期，並清楚區分「指控」與「已判決」；家屬案件要寫明「非本人」。
- `promise`：
  - 未曾當選「同一職務」者：`{na:"未曾當選本職，無過往任期政見可追蹤。"}`（官派職、其他職務也是 na，但可註明）。
  - 現任者（或曾任者）：以上一屆（111年，2022）中選會公報政見逐條比對 2022-12 至 2026-11 的實際結果：已實現（結果發生＋有本人出力證據）／部分（進行中，或已完成但查不到本人角色）／未實現／無法查證（不計入分母）。`rate = round((done + 0.5*partial) / (done+partial+no) * 100)`；`basis:"111年（2022）公報政見"`；`items` 每項 `{s:"已實現"|"部分"|"未實現"|"無法查證", t, u}`；`note` 寫限制（議員無行政權、依新聞判定等）。
  - 現任市長：以 2022 市長公報政見比對。

### question 物件
```
{ cat:"分類", q:"題目",
  o:[ { t:"選項文字", s:{c1:1, c4:0.8, ...} 或 null, why:"依據：哪位候選人公報哪一條" } ],
  ex:{ bg:"背景說明", o:["選項A說明","選項B說明",...], src:["url",...] } }
```
規則：
- 題目分類要涵蓋：交通、居住都更、醫療、長者、育兒、教育、經濟產業／青年、環境、治安、社福、在地議題（該選區特有爭議）等，視候選人政見而定。
- 每個選項必須對應到**至少一位候選人公報上的具體政見**（s 分數 1 = 明確主張、0.8/0.6 = 相近主張；未列出的候選人自動得 0.3）。「沒有特別意見」類選項 `s:null`（不計分）。
- 題目要能**區分**候選人：避免每位候選人都主張的選項；每位候選人最好至少在 2 題中有分數 ≥0.8。
- **不要出冷門、幾乎沒人討論、或明顯獵奇的議題**（例如某單一候選人的極端主張若社會上沒有討論，不要單獨成題；可併入一般題的選項）。
- 選項文字不可出現候選人姓名；`why` 可以寫姓名。
- `ex.bg`：2–4句，該議題目前在該市／該區的現況與爭點。`ex.o`：每個選項 2–4 句白話說明「實際會怎麼做、規模／成本、支持與批評理由」，讓一般民眾看懂選項的真正差別，並說明議員／市長實際能做什麼。不可寫候選人姓名，不可評斷優劣。`ex.o.length` 必須等於 `o.length`。

## 研究方法（必須照做）
1. **下載官方公報**：從 https://bulletin.cec.gov.tw/?dir=01%E9%81%B8%E8%88%89%E5%85%AC%E5%A0%B1%2F05%E7%9B%B4%E8%BD%84%E5%B8%82%E8%AD%B0%E5%93%A1%2F115%E5%B9%B4 （議員）或 `.../03直轄市長/115年`（市長）目錄找到檔案，用 curl 下載到你自己的新空資料夾 `/tmp/claude-0/-home-user-usagi-game/53d9a01e-6bd6-5033-9ffc-ffd1b841f1d8/scratchpad/<id>/`。`pdftotext -layout` 抽文字（雙欄會交錯，要用版面判斷哪段屬於誰；也可試 `pdftotext -raw`）；政見常是圖片：`pdfimages -png` 取出後用 Read 工具看圖逐字讀。**每位候選人的號次、姓名、政黨、學經歷、政見都以公報為準。**
2. **上一屆公報**（現任者兌現度）：111年目錄同上，把 115 換 111。
3. **網路查證**：WebSearch（必要時 WebFetch；curl 可連 cna.com.tw、udn.com、news.ltn.com.tw、chinatimes、newtalk、mirrormedia、pts、tfc-taiwan、zh.wikipedia.org、議會網站）。查：學經歷是否屬實、問政紀錄、獲獎評鑑、爭議、司法案件（起訴／判決結果與審級）。
4. **交叉驗證**：每筆負面紀錄至少找 1 個可信媒體來源；有爭議的寫雙方說法。查不到就寫查無，不要猜。
5. 中立：各候選人篇幅相當；不使用政黨色彩字眼；不下評價。
